# Origin

This repository extracts the source-census engine from the Personal Intelligence Dashboard as a focused, reusable utility.

The parent project retains a copy so its local workflow is self-contained. This standalone version changes the output boundary from “inside the Dashboard checkout” to an explicitly selected dedicated directory, while preserving the allowlist, no-indirection, source-containment, full-hash, append-only evidence, and duplicate-candidate laws.

No original archive, real source configuration, inventory output, path list, filename list, or personal evidence is included.
